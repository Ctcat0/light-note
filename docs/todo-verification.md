# Todo List 真实环境验收清单

## 前置条件

1. `todo_lists`、`todos` 已创建，客户端权限均为“所有用户不可读写”；
2. `uq_todos_owner_request` 和 `docs/database-setup.md` 中的待办查询索引均已可用；
3. `cloudfunctions/todo` 已选择“上传并部署：云端安装依赖”；
4. 微信开发者工具编译无错误。

## 开发环境验证记录

2026-07-22 已完成集合、仅管理端权限、索引和 `todo` 云函数部署。真实微信上下文下已验证首次默认清单与空态、新增、编辑、完成、撤销完成、今天/近期/全部/完成视图及默认清单筛选；页面原生按钮宽度导致的卡片挤压也已修正并重新编译确认。逾期组合、分页、越权和幂等由自动化测试覆盖；测试/生产环境仍需逐环境重复本清单。

## 基础闭环

1. 首次进入待办页能看到“默认清单”，空数据展示 empty 状态；
2. 新建无截止日期任务，确认它只出现在“全部”，不进入今天、近期或逾期；
3. 新建今天的日期型任务和未来 7 天内任务，分别确认今天、近期视图；
4. 新建一个早于当前时刻的 datetime 任务，确认进入逾期；日期型任务不得伪造午夜 `dueAt`；
5. 编辑标题、描述、优先级和截止方式后刷新，数据保持一致；
6. 完成任务后 `completedAt` 写入且任务进入“完成”；撤销后 `completedAt` 清空；
7. 删除前必须出现二次确认；取消不删除，确认后列表和详情均不可见。

## 异常与隔离

1. 连续点击保存/完成不会产生重复记录或重复版本递增；
2. 断网或云函数失败时页面保留输入并允许显式重试；
3. 使用另一微信用户登录后看不到前一用户的清单和任务；
4. 伪造其他用户的 todoId 读改删返回同类不存在错误；
5. 列表超过 20 条时上拉分页无重复、无漏项，失败后可以局部重试。
